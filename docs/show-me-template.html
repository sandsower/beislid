Visual evidence portfolio

Don’t tell me. Show me.

This template demonstrates the expected shape of a polished local HTML artifact: summary up front, navigable sections, evidence blocks, media panels, command logs, and provenance.

● PASS / EXPLANATORY Mode: mixed Media may contain sensitive data

01 Overview

What this deck proves or explains

Start with the human decision this artifact supports. Keep it direct.

Subject

The change, subsystem, document set, or behavior being shown.

Status

PASS, FAIL, INCOMPLETE, EXPLANATORY, or another explicit status.

Evidence

Commands, diffs, media, citations, and asset references included below.

03 Evidence

Command output belongs in the artifact

Every command block should include command, cwd, timestamp, exit status, and a path to the full log when available.

04 Media

Screenshots, video, GIFs, and diagrams

Use media when behavior is easier to inspect visually than to read in prose.

Image/video/GIF panel
Caption: what to notice, source/capture method, and sensitivity warning.

05 Provenance

Make the artifact auditable

Record enough metadata to understand where the deck came from without dumping the full chat transcript.

Redaction note: text logs should be scanned for likely secrets. Media is not considered redacted unless explicitly processed by a redaction tool.
